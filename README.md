# ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/Avaneesh-23/Hugging-Face-LangGraph-Assignment.git
```

Move into the project directory:

```bash
cd Hugging-Face-LangGraph-Assignment
```

Create a virtual environment:

```bash
python -m venv venv
```

Activate the virtual environment:

## Windows

```bash
venv\Scripts\activate
```

## Linux / Mac

```bash
source venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

---

# 🔑 Environment Variables

Create a `.env` file in the root directory.

Example:

```env
GOOGLE_API_KEY=your_gemini_api_key
HUGGINGFACEHUB_API_TOKEN=your_huggingface_token
```

# 🧠 About LangGraph

LangGraph is a framework for building stateful, multi-actor AI applications using graph-based workflows. It extends LangChain capabilities with cyclic graphs, memory, and agent orchestration.
